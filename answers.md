1. What is the difference between git clone and git init?
git clone clones the existing Github repository in your computer.
git init initializes a git repository within an existing directory

2. What does git status tell you?
The command git status provides information about the current branch along with modified, staged, and untracked files.

3. What is the purpose of git add?
git add adds the changed files to the staging area before committing.

4. Difference between git diff and git diff --staged?
git diff shows unstaged changes, while git diff --staged shows staged changes.

5. What is the purpose of git commit?
git commit saves the staged changes in Git.

6. Difference between git log and git log --oneline?
git log shows detailed commit history, while git log --oneline shows it in a short form.

7. What information can you see using git show?
It shows the details and changes of a particular commit.

8. What does git pull do?
git pull gets the latest changes from GitHub to the local repository.

9. What does git push do?
git push sends our local commits to GitHub.

10. What is a Git branch?
A branch is a separate version of the project where we can work on changes.

11. What does git checkout do?
git checkout is used to switch between branches.

12. Why do developers create feature branches?
To work on new features without disturbing the main branch.

13. What is a Pull Request?
A Pull Request is a request to add changes from one branch to another.

14. Why should a Pull Request be reviewed before merging?
To check for mistakes and make sure the changes are correct.

15. Difference between main and feature-pages?
main is the main branch, while feature-pages is used to work on the pages separately.
